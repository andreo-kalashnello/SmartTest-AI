## Що зробити (по кроках)

### 1. Реєстрація викладача
1. Відкрити http://smarttestai.duckdns.org (подивитися лендінг)
2. Відкрити http://smarttestai.duckdns.org/register чи натиснути кнопку «Реєстрація»
2. Вказати імʼя, email, пароль → зареєструватися.  
3. Має відкритися **дашборд** (список тестів, спочатку порожній).

### 2. Створити тест через AI
1. Натиснути **«Новий тест»** (або `/dashboard/tests/new`).  
2. Заповнити, наприклад:  
   - назва: «Алгебра»  
   - тема: «Квадратні рівняння»  
   - кількість питань: 3–5  
   - складність: на вибір  
   - мова: **українська**  
3. Додати текст матеріалу **або** завантажити фото конспекту.  
4. Натиснути **«Створити з ШІ»** (чекати 30–90 с).  
5. Переглянути згенеровані питання, за потреби змінити → **Зберегти**.  
6. На дашборді знайти **PIN** цього тесту (6 цифр).


### 3. Учень проходить тест
1. Відкрити **інкогніто** або інший браузер.  
2. Перейти на http://smarttestai.duckdns.org/join  
3. Ввести **PIN** з кроку 2 і будь-яке **ПІБ** (напр. «Тестовий Учень»).  
4. Відповісти на питання → **Завершити тест**.  
5. Переглянути **результат** (бал).

### 4. Викладач перевіряє спроби
1. Повернутися в звичайному вікні, увійти як той самий викладач (якщо вийшли — `/login`).  
2. Відкрити створений тест → **Спроби**.  
3. Переконатися, що є запис з ПІБ учня та балом.

### 5. (За бажанням) Редагування тесту
1. Відкрити тест → **Редагувати**.  
2. Змінити текст питання або варіанти → зберегти.

## Якщо щось не працює

- **Unauthorized** після входу — вийти, очистити cookie для сайту, увійти знову.  
- **AI не генерує** — спробувати коротший текст матеріалу або лише тему без файлу; перевірити кроки 3–4 без AI (створити питання вручну в редакторі після збереження чернетки).
