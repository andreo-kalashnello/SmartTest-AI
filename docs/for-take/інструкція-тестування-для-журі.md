## Ролі

| Роль | Як увійти |
|------|-----------|
| **Викладач** | `/register` → обрати «Викладач» → дашборд `/dashboard` |
| **Учень (з акаунтом)** | `/register` → «Учень», клас (напр. 10-А) → кабінет `/student` |
| **Учень (гість)** | Без реєстрації: `/join` + PIN тесту + ПІБ |

Учень **може** пройти тест і без акаунта, і після входу (імʼя підставиться на `/join`).

## Що зробити (по кроках)

### 1. Реєстрація викладача
1. Відкрити http://smarttestai.duckdns.org/register  
2. Обрати **Викладач**, імʼя, email, пароль → зареєструватися.  
3. Має відкритися **дашборд** (список тестів).

### 2. Створити тест через AI
1. **«Новий тест»** (або `/dashboard/tests/new`).  
2. Тема, кількість питань, мова **українська**, текст або фото матеріалу.  
3. **«Створити з ШІ»** (30–90 с) → переглянути → **Зберегти**.  
4. Запамʼятати **PIN** (6 цифр).

### 3а. Учень-гість
1. Інкогніто → http://smarttestai.duckdns.org/join  
2. PIN + будь-яке ПІБ → пройти тест → результат.

### 3б. Учень з реєстрацією (за бажанням)
1. Інкогніто → `/register` → **Учень**, клас 10-А.  
2. Увійти → кабінет `/student` (статистика — демо-дані).  
3. `/join` → PIN; ПІБ уже заповнене.  
4. Опційно: **Налаштування** — код класу від вчителя (`/dashboard/classes` у вчителя).

### 4. Спроби у викладача
1. Той самий акаунт вчителя → тест → **Спроби** — запис з ПІБ і балом.

### 5. AI-помічник (демо)
1. Кнопка чату внизу справа на будь-якій сторінці — можна запитати про PIN, реєстрацію (відповіді поки шаблонні).
